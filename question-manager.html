Question Bank Manager

Add, edit, duplicate, and export questions without editing JavaScript. Works entirely in your browser. Changes are not live until you publish the exported JSON file.

Important: This is a client-side editor, not a password-protected admin area. Anyone with the URL can open it, but nobody can publish changes to your GitHub repository without repository access. Do not put private information in the question bank.

Download your updated file, then replace questions.json in your GitHub repository and commit. The game will load the new questions automatically.
